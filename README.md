# Makhan Carpenter - Luxury Furniture & Woodworking Atelier

A high-end, bespoke custom furniture and architectural carpentry portfolio website for **Makhan Carpenter**, celebrating over **20 years of master woodworking excellence across Uttar Pradesh (UP) and Alwar (Rajasthan)**.

---

## ✨ Features

- **Luxury Atelier Aesthetic**: Deep obsidian charcoal, rich walnut timber tones, warm ivory, and muted bronze accents.
- **Hero & Brand Statement**: *"Crafted by Hand. Designed for Life."* with 20+ years UP & Alwar regional trust badges.
- **Our Craftsmanship Showcase**: Masonry portfolio with 10 detailed custom projects across all categories (Wardrobes, Dining, Bedroom, Kitchen, Office, Doors, Living Room, Custom), with image hover zoom and interactive **case-study detail modals**.
- **8 Bespoke Services**: Custom Furniture, Wardrobes & Closets, Modular Kitchens, Wooden Beds, Dining Tables, Office Workstations, Wooden Doors, and Interior Woodwork + **Explore Service detail drawers**.
- **Why Choose Makhan Carpenter**: 6 trust pillars (*20+ Years Mastery, 100% Made-to-Measure, Authentic Cured Timber, Millimeter Joinery, Hand-Rubbed Finish, Transparent Pricing*).
- **Craftsmanship Process**: 8-stage interactive timeline (*From Raw Wood to Refined Furniture*).
- **Interactive Before & After Slider**: Draggable comparison slider featuring 4 real transformation cases.
- **About Makhan Carpenter**: Artisan story highlighting 20+ years of mastery in UP & Alwar.
- **Materials Explorer**: Interactive tactile guide to solid CP Teak (Sagwan), American Walnut, European Oak, IS:710 Marine Plywood, and Architectural Hardware.
- **Testimonials & Statistics**: Verified reviews from Alwar, Lucknow, Noida, and Agra, paired with 20+ years, 450+ projects, and 100% custom metrics.
- **Visual Gallery**: Full-screen visual archive with category filters and interactive image lightbox.
- **4-Step Quote Request Wizard**: Guided custom furniture builder with direct pre-filled **WhatsApp dispatch**.
- **Contact Section & Footer**: Dedicated contact channels, on-site consultation booking, and 24/7 floating WhatsApp button.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite (TypeScript)
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Animations**: Framer Motion + Canvas Confetti
- **Typography**: Cormorant Garamond (Editorial Serif) & Plus Jakarta Sans (Clean Modern Sans)

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

## 📝 Customization

All business details, phone numbers, WhatsApp links, emails, projects, services, and testimonials are centralized and easily editable in:
`src/data/siteContent.ts`
